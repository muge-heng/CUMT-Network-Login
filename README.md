# CUMT Network Login - 中国矿业大学校园网自动登录工具

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> 🎯 中国矿业大学校园网自动登录、连接监控与智能维护工具
>
> 本软件代码全程使用 **AI 生成和优化**，经过充分测试，完美可用。

## 📋 功能概要

| 功能 | 说明 | 默认状态 |
|------|------|:--------:|
| **自动登录** | 启动后检测网络状态，自动完成校园网认证 | 可选 |
| **保持联网** | 后台持续监控网络，断线自动重新认证 | 可选 |
| **密码加密存储** | 使用 AES 对密码进行本地加密保存，保障安全 | 勾选后启用 |
| **系统托盘运行** | 支持最小化到托盘，后台静默运行 | ✅ 默认 |
| **开机自启** | 通过 Windows 任务计划程序实现开机启动 | 可选 |
| **网络监控** | 实时带宽、延迟曲线、连接统计 | ✅ 默认 |
| **登录历史** | 记录每次登录的时间、账号、状态、时长 | ✅ 默认 |
| **多账号管理** | 支持添加、切换、导入导出多个校园网账号 | 可选 |
| **断网自动连WiFi** | 检测到断网时自动连接 CUMT_Stu WiFi | 可选（无线用户） |
| **夜间智能节能** | 夜间校园网断网后暂停重试，省电省资源 | 可选（笔记本推荐） |

> 💡 **推荐配置**：勾选"记住密码" + "自动登录" + "保持联网" 即可实现全自动体验。

## 🚀 快速开始

### 方法一：直接运行 exe

下载 `dist/campuslogin.exe`，双击运行即可。你可以直接从[release](https://github.com/muge-heng/CUMT-Network-Login/releases)下载。

> Windows SmartScreen 可能弹出警告，点击"更多信息"→"仍要运行"即可。

### 方法二：从源码运行

```bash
pip install customtkinter requests cryptography psutil pystray Pillow win10toast
python Original_Python_Project/campus_login_optimized.pyw
```

### 首次使用

1. 输入校园网账号和密码
2. 选择运营商（校园网 / 移动 / 联通 / 电信）
3. 勾选 **记住密码** → 自动勾选 **自动登录**（推荐）
4. 可选：**保持联网**（断线自动重认证）
5. 点击 **登录**，自动完成认证

## 🔧 功能介绍

### 自动登录 + 保持联网

程序会检测当前网络连通性，如果无法访问互联网（检测 `https://www.baidu.com`），则自动向校园网认证服务器发送登录请求。

- **自动登录**：启动时自动完成一次登录
- **保持联网**：开启后在后台持续检测（每 0.5 秒），发现断线立即重新认证
- 登录基于 ePortal 协议（`http://10.2.5.251:801/eportal/`），自动携带账号、密码、本机 IP 和 MAC 地址

### 断网自动连接校园网 WiFi

> 此功能与"保持联网"是**两个独立的功能**，无需同时开启。一般只需开启"保持联网"即可。

当检测到网络断开时，自动执行 `netsh wlan connect name="CUMT_Stu"` 连接校园网无线网络，连接成功后再发起认证登录。

- ✅ **无线用户推荐**：配合"保持联网"使用，断网后自动连 WiFi + 自动认证
- ⚠️ **有线用户请注意**：如果你使用的是宿舍网口直连，**建议不要勾选此功能**，因为自动连接 WiFi 可能会中断你的有线连接，造成不必要的打扰

### 夜间智能节能

针对校园网**夜间可能断网**（通常 23:30 - 06:00）的特性，当检测到 1 分钟内连续 3 次以上登录失败时，自动暂停网络重试，早上 6:00 自动恢复检测。

- 有效减少无效网络请求，降低 CPU 和电量消耗
- **笔记本用户推荐开启**

### 密码安全

- 使用 `cryptography.fernet`（AES 对称加密）加密密码
- 密钥文件（`.key`）与配置文件（`.json`）分离存储
- 配置文件泄露也无法解密密码
- **密码仅存储在本地，不会上传到任何第三方服务器**

### 监控与统计

- **实时网速**：显示上传/下载速度（自适应 B/s ~ MB/s）
- **延迟曲线**：实时绘制 ping 百度延迟图表
- **连接统计**：总连接次数、成功率、在线时长、网络使用量
- **登录历史**：记录每次登录时间、账号、运营商、状态、会话时长

### 系统托盘

关闭窗口后自动最小化到系统托盘，右键菜单包含：显示窗口 / 手动登录 / 切换保持联网 / 退出。

### 开机自启

通过 Windows `schtasks` 注册开机自启任务（登录后延迟 30 秒），支持 `--silent` 静默模式后台登录后自动退出。

## 🏗️ 设计原理

### 网络检测流程

```
启动 → 加载配置
  ├─ 开启自动登录 → 发起校园网认证
  │    ├─ 成功 → 进入保持联网监控
  │    └─ 失败 → 显示错误
  └─ 未开启 → 等待用户操作
```

### 保持联网循环

```
[后台线程]
  ├─ (可选) 夜间判断：23:30-06:00, ≥3次失败/分钟 → 挂起到6:00
  ├─ 检测网络: ping baidu.com
  │    ├─ 正常 → 更新状态
  │    └─ 断开 → (可选) 连CUMT_Stu WiFi → 发起认证
  └─ 等待0.5秒 → 循环
```
