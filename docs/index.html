💡 功能亮点

一站式校园网管理

从登录到监控，从节能到安全，覆盖校园网使用的每一个环节。

🔓

自动登录

启动后自动检测网络连通性，发现断网立即通过 ePortal 协议完成校园网认证，无需手动打开浏览器。

🔄

保持联网

后台 0.5 秒轮询监测网络状态，一旦检测到断线（ping 百度失败），立即自动重新认证，真正做到永不掉线。

🌙

夜间智能节能

23:30–06:00 期间，1 分钟内连续 3 次登录失败自动暂停重试，避免无效请求浪费 CPU 和电量，早晨 6 点自动恢复。

🔐

密码加密存储

使用 AES（Fernet）加密密码，密钥与配置分离存储，配置文件泄露也无法解密密码。密码仅存本地，不上传任何服务器。

👥

多账号管理

支持校园网、中国移动、中国联通、中国电信四类运营商账号，可添加、切换、导入导出多个账号。

📊

实时监控面板

实时显示上传/下载网速、延迟曲线、连接成功率、在线时长；完整记录每次登录的历史时间、账号和状态。

📌

系统托盘

关闭窗口自动最小化到系统托盘，右键菜单含显示窗口 / 手动登录 / 切换保持联网 / 退出等快捷操作。

⚡

开机自启

通过 Windows 任务计划程序注册开机自启任务（延迟 30 秒），支持 --silent 静默模式后台登录后自动退出。

⚙️ 工作原理

启动到保持联网，全自动运行

用户只需首次配置账号密码，后续开机即用，完全无需操心。

1

程序启动

加载加密配置 → 解密账号密码 → 检测网络连通性（ping baidu.com）

2

自动登录

通过 ePortal 协议向 10.2.5.251:801 发送认证请求，携带账号（含运营商后缀）、密码、本机 IP 和 MAC 地址

3

保持联网循环

每 0.5 秒检测一次网络 → 正常则更新状态继续等待 → 断开则自动（可选连接 CUMT_Stu WiFi）→ 重新发起认证

4

夜间节能模式

若在夜间时段（23:30–06:00）检测到 1 分钟内 ≥3 次失败，自动挂起重试逻辑，早 6 点自动恢复
